## 🎓 LMS (Learning Management System) nədir?

**LMS (Öyrənmə İdarəetmə Sistemi)** — onlayn təhsil və kursların idarə olunması üçün nəzərdə tutulmuş platformadır. Bu sistem vasitəsilə müəllimlər dərs materiallarını yükləyə, testlər yarada və tələbələrin nəticələrini izləyə bilirlər.  
Tələbələr isə öz hesabları ilə sistemə daxil olub kurslara qoşula, tapşırıqları yerinə yetirə və sertifikat əldə edə bilirlər.

### 🔧 Əsas xüsusiyyətlər:
- 📚 Kursların və dərs modullarının idarə edilməsi  
- 👨‍🏫 Müəllim və tələbə rolları  
- 🧾 İmtahan və tapşırıq sistemi  
- 📈 Proqresin və nəticələrin izlənməsi  
- 📩 E-poçt bildirişləri və inteqrasiya  
- 🔐 Təhlükəsiz giriş (JWT və e-poçt təsdiqi)

### 🚀 Texnologiyalar:
- Backend: **ASP.NET Core (C#)**  
- Database: **MS SQL Server**  
- Authentication: **JWT Token + Identity**  
- Mapping: **AutoMapper**  
- API Layer: **LmsApiApp**

Bu layihə onlayn tədris prosesini asanlaşdırmaq və təhsil müəssisələrinə çevik idarəetmə imkanı yaratmaq məqsədi daşıyır.
